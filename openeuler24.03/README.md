# openEuler 24.03 LTS

> **Author:** 王有政<br>
> **编码:** UTF-8

本目录用于维护 openEuler 24.03 LTS 的服务器初始化和发行版专项生产实践。

## 版本定位

- openEuler 社区版可以免费使用，商业发行版和商业技术支持另行付费。
- 本目录只维护 24.03 LTS 系列；部署时应选择仍在支持期内、经过验证的 Service Pack。
- openEuler LTS 社区生命周期为 4 年，其中包含 2 年维护支持和 2 年延长支持，可按官方机制申请延长至 6 年。
- 有国产化要求且具备自主运维能力时，openEuler 24.03 LTS 是本项目新服务器的默认选型。

正式信创采购还必须核验项目采购目录、硬件兼容性、应用认证和原厂服务要求，不能只根据操作系统名称判定是否满足国产化验收要求。
