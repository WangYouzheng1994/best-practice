# Ubuntu Server 24.04 LTS

> **Author:** 王有政<br>
> **编码:** UTF-8

本目录用于维护 Ubuntu Server 24.04 LTS 的服务器初始化和发行版专项生产实践。

## 版本定位

- Ubuntu Server 24.04 LTS 可以免费使用，Ubuntu Pro 和商业技术支持另行付费。
- Ubuntu 24.04 LTS 提供 5 年标准安全维护，启用 Ubuntu Pro 后可以延长支持周期。
- 本目录只维护 24.04 LTS 系列；部署时应使用仍在支持期内并经过验证的更新版本。
- 云原生、Kubernetes、AI/GPU 和公有云场景优先评估 Ubuntu Server 24.04 LTS。
- Ubuntu 不属于国产化操作系统，正式国产化项目不应将其作为国产操作系统申报。

Ubuntu 使用 DEB/APT 软件生态，不能直接照搬 Rocky Linux、openEuler 或 CentOS 的 RPM/DNF/YUM 安装步骤；只有发行版相关操作存在差异时，组件文档才放入本目录。
