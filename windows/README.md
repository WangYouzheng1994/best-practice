# Windows

> **Author:** 王有政<br>
> **编码:** UTF-8

本目录用于维护 Windows 宿主机与 Windows Server 相关的本机实验、虚拟化和管理实践。

## 目录定位

- 本目录文档面向本机实验、测试和开发环境，不构成生产部署标准；生产环境仍以 `centos7.9/`、`rockylinux9/`、`openeuler24.03/`、`ubuntu24.04/` 中的服务器手册为准。
- 虚拟化平台统一以 VMware Workstation Pro 为基准；如需 ESXi、Hyper-V 或 Proxmox，另行编写独立文档。
- 客户机操作系统以 Windows Server LTSC 版本为准，选型时优先核对微软官方生命周期的支持起止时间。
- 文档中的版本号、下载入口和 IP 段均为示例，实施前必须核对厂商官网当前版本，并完成环境确认。
